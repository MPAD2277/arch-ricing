Arch Linux Ricing Journey

Halo! Selamat datang di simulasi desktop gw. Website ini dibangun untuk menceritakan proses gw ngebangun setup Linux yang minimalis, keyboard-centric, tapi tetep keren dipandang. Semua berawal dari rasa penasaran nyoba Arch Linux dan ngerakit lingkungan desktop dari nol pakai Hyprland.

Desktop Showcase

Ini adalah tampilan asli desktop gw yang lagi jalanin TTY-Clock, Btop (system monitor), dan Neofetch dengan *wallpaper* gelombang laut bernuansa gelap (Glassmorphism).

Konfigurasi Hyprland (Wayland)

Hyprland ngasih performa Wayland yang super mulus dengan animasi yang eye-candy. Gw ngatur *gaps* dan efek *blur* transparan (seperti yang lu lihat di jendela website ini) langsung via hyprland.lua. 

-- Mengatur efek Glassmorphism (Blur)
hl.config({
    decoration = {
        rounding = 5,
        active_opacity = 1.0,
        inactive_opacity = 0.75,
        
        blur = {
            enabled = true,
            size = 5,      -- Ukuran blur
            passes = 1,
        },
    }
})

Pendekatan TUI / CLI

Sebagai penganut sekte terminal, gw udah ninggalin GUI *File Manager* berat. Semuanya dibikin cepat, *keyboard-driven*, dan konsisten pakai aksen warna Cyan (#33ccff) biar matching banget sama *wallpaper* dan bikin mata nggak cepet lelah.
